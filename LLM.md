## what this platform is

One `helm install` that wires together:
- Harbor — container registry (OCI + Helm charts)
- Gitea — git server + Actions CI runner
- OpenBao — secrets management (open-source Vault fork)
- Crossplane — cloud resources as Kubernetes objects
- ArgoCD — GitOps CD — watches Gitea, syncs cluster

Every connection between components lives in `wiring/` as a plain YAML file.
The wiring is the value — not the components themselves.

---

## install phases

```
helm install platform ./platform
  → Phase 1: helm installs component charts
    → Phase 2 (hook weight 0): init job
        seeds Gitea, configures OpenBao, writes platform-wiring-tokens Secret
      → Phase 3 (hook weight 10): wiring job
          reads tokens, sed-substitutes wiring/ files, kubectl applies them
```

The only contract between Phase 2 and Phase 3 is the `platform-wiring-tokens` Secret.

## wiring/ files — the joints

| file | from | to | what it does |
|---|---|---|---|
| `argocd-repo-secret.yaml` | Gitea | ArgoCD | ArgoCD authenticates to Gitea using an API token |
| `argocd-applications.yaml` | Gitea | ArgoCD | ArgoCD Application watching deploy/ in the Gitea demo repo |
| `runner-token-secret.yaml` | Gitea | cluster | Gitea Actions runner registration token |
| `harbor-pull-secret.yaml` | Harbor | cluster | Docker pull secret for Harbor registry |
| `openbao-k8s-auth.yaml` | OpenBao | cluster | OpenBao Kubernetes auth — allows pods to authenticate with OpenBao |
| `crossplane-providers.yaml` | Crossplane | cluster | Crossplane Kubernetes provider (in-cluster resource management) |

Every wiring file has `platform/wiring`, `platform/from`, `platform/to` labels.
Query all wiring objects: `kubectl get all -A -l platform/wiring`

## common failure points

| symptom | check |
|---|---|
| ArgoCD shows repo unreachable | `wiring/argocd-repo-secret.yaml` |
| Runner not picking up jobs | `wiring/runner-token-secret.yaml` |
| Pods can't read secrets from OpenBao | `wiring/openbao-k8s-auth.yaml` |
| Image pull fails from Harbor | `wiring/harbor-pull-secret.yaml` |
| init Job failed | `kubectl logs job/platform-init -n platform` |
| wiring Job failed | `kubectl logs job/platform-wiring -n platform` |
| partial install | `kubectl get secret platform-wiring-tokens -n platform` |

## how to extend

**Add a new ArgoCD Application:**
Copy `wiring/argocd-applications.yaml`, change `path` and `namespace`, `kubectl apply -f`.

**Add a new component:**
1. Add it to `Chart.yaml` dependencies
2. Add a wiring file in `wiring/` describing the connection
3. Add the sed + kubectl apply block in `templates/wiring-job.yaml`
4. Add init steps in `files/gitea-init.sh` if needed
5. `helm upgrade platform ./platform`
